# Orbit — Upcoming Events Scheduler

Separated version of the single-file dashboard.

## Structure

- `index.html` — HTML structure and content
- `css/style.css` — all CSS, themes, responsive layout, animations
- `js/app.js` — all JavaScript interactions

## Run

Keep the folder structure unchanged and open `index.html` in a browser.

The HTML references the stylesheet with `css/style.css` and the JavaScript with `js/app.js`.

The project keeps the original Google Fonts `@import`, so an internet connection is needed for those fonts; the application itself has no framework/build dependency.
